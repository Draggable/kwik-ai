Auto-tag posts, generate descriptions, and create featured images with AI. Works with Ollama, OpenRouter, and OpenAI.

== Description ==

Kwik AI automatically generates relevant tags and descriptions for your content using AI, and can create AI featured images. It supports multiple AI providers including **Ollama** (local models), **OpenRouter** (cloud models), and **OpenAI** (GPT models).

**Features**

* **AI Tags Generation** – Generate relevant tags from images and text content, with a preview/edit step before applying. Supports attachments, blocks, and galleries.
* **AI Description Generation (Meta Box)** – Generate descriptions from a post's images and insert them into the post content.
* **AI Description Block** – A Gutenberg block with built-in generation controls, customizable length (50–500 words), and content that stays inside the block.
* **AI Featured Image Generation (FAL.AI)** – Draft an image prompt from your post, preview the result, and set it as the featured image. Uses FAL.AI's queue API so slow image models don't time out.
* **Multiple AI Providers** – Ollama (run models locally), OpenRouter (hundreds of models via one API), and OpenAI (GPT models).

The plugin connects to third-party AI services you configure. Tags and descriptions are generated by sending your post content (text and/or images) to the provider you select.

**Third-party services**

This plugin can send your post content to whichever provider you configure:

* Ollama – self-hosted; data goes to the host you configure. https://ollama.com/
* OpenRouter – https://openrouter.ai/ ( Terms: https://openrouter.ai/terms , Privacy: https://openrouter.ai/privacy )
* OpenAI – https://openai.com/ ( Terms: https://openai.com/policies/terms-of-use/ , Privacy: https://openai.com/policies/privacy-policy/ )
* FAL.AI (optional, for featured-image generation) – https://fal.ai/ ( Terms: https://fal.ai/terms , Privacy: https://fal.ai/privacy )

== Installation ==

1. Upload the plugin to your WordPress site and activate it.
2. Go to **Settings > Kwik AI**.
3. Select your AI provider (Ollama, OpenRouter, or OpenAI), set the endpoint/model, and enter any API credentials.
4. For image analysis, use a vision-capable model (e.g. `gemma3:27b` or `llava:13b` for Ollama; `gpt-4o` for OpenAI).
5. (Optional) Add a FAL.AI API key and choose an image model to enable AI featured images.
6. Enable the post types you want Kwik AI to appear on.

== Frequently Asked Questions ==

= Do I need an API key? =

For OpenRouter and OpenAI you need an API key. For Ollama or local LLM you only need a running Ollama server (local or remote). FAL.AI requires its own key and is only needed for featured-image generation.

= Does this send my content to a third party? =

Yes, when you generate tags, descriptions, or images, the relevant post content is sent to the AI provider you configure. See the third-party services list in the Description for links to each provider's terms and privacy policy.

= What models work for image analysis? =

Any vision-capable model: for example `gemma3:27b` or `llava:13b` on Ollama, `openai/gpt-4o` on OpenRouter, or `gpt-4o` / `gpt-4o-mini` on OpenAI.

= Can I use a different model for text-only tasks? =

Yes. In settings you can set a dedicated Text Model for text-only generation (image prompts and URL-based descriptions) when your main model is vision-only.
