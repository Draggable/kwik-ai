<h2 class="wp-block-heading has-large-font-size">Overview</h2>
<p class="wp-block-paragraph">Kwik AI automates content metadata generation for WordPress. Generate relevant tags, write engaging descriptions, craft concise excerpts with controllable tone, and create stunning featured images -- all from within the WordPress editor.</p>
<p class="wp-block-paragraph">It supports multiple AI providers: <strong>Ollama</strong> (run models locally for full data privacy), <strong>OpenRouter</strong> (hundreds of cloud models via one API key), <strong>OpenAI</strong> (GPT models), and <strong>FAL.AI</strong> (AI image generation). Vision-capable models can analyze images directly, extracting subjects, activities, and themes from your post content.</p>
</div>

<h2 class="wp-block-heading has-large-font-size">Features</h2>
<h3 class="wp-block-heading">AI Tags Generation</h3>
<p class="wp-block-paragraph">Generate relevant tags from both image and text content. The plugin reads images from attachments, Gutenberg blocks, and galleries, then produces a preview you can edit before applying. No more manual tagging -- generate and review in seconds.</p>
<h3 class="wp-block-heading">AI Description Generation</h3>
<p class="wp-block-paragraph">Three ways to generate descriptions for your content:</p>
<ul class="wp-block-list">
<li><strong>From images</strong> -- Analyze post images with vision models and generate engaging descriptions with configurable word counts (50 to 500 words).</li>
<li><strong>From URLs</strong> -- Paste one or more URLs and Kwik AI scrapes the pages, summarizes the content, and generates a description based on that summary. Perfect for posts that link to external resources.</li>
<li><strong>As a Gutenberg block</strong> -- A native block with built-in generation controls. Customize length, choose your source (images, URLs, or page content), and the output stays inside the block.</li>
</ul>
<h3 class="wp-block-heading">AI Excerpt Generation</h3>
<p class="wp-block-paragraph">Generate post excerpts from title and content in four tones: <strong>Technical</strong> (precise and factual), <strong>Straight</strong> (clear and direct), <strong>Excerpt</strong> (editorial style that teases the central idea), and <strong>Pithy</strong> (lively and compact). Length is adjustable from 20 to 80 words.</p>
<h3 class="wp-block-heading">AI Featured Image Generation</h3>
<p class="wp-block-paragraph">Create AI-generated featured images directly from your post content using FAL.AI. The two-step workflow reads your entire post, distills it into a visual theme, and crafts a creative image prompt. Preview and edit the prompt before submitting. Choose from FLUX, Stable Diffusion 3.5, Ideogram V2, Recraft V3, and more. Configure image size from six presets: square, portrait, and landscape options.</p>
</div>

<h2 class="wp-block-heading has-large-font-size">Technical Highlights</h2>
<ul class="wp-block-list">
<li><strong>WordPress 5.6+ compatible</strong> -- works with all recent WordPress versions including 7.0</li>
<li><strong>PHP 7.4+ required</strong> -- standard modern PHP requirement</li>
<li><strong>Multi-provider support</strong> -- Ollama (local), OpenRouter (cloud), OpenAI (GPT), FAL.AI (images)</li>
<li><strong>Vision model support</strong> -- analyze images with models like gemma3:27b, llava:13b, or GPT-4o</li>
<li><strong>Dedicated text model</strong> -- set a separate model for text-only tasks independent from your vision model</li>
<li><strong>FAL.AI integration</strong> -- async image generation via queue API with live model catalog (cached 12 hours)</li>
<li><strong>URL content scraping</strong> -- extract and summarize content from any public URL</li>
<li><strong>Gutenberg block included</strong> -- native WordPress block editor integration</li>
<li><strong>AJAX-powered</strong> -- generation happens asynchronously without page reloads</li>
<li><strong>Secure by design</strong> -- nonce verification, input sanitization, SSRF protection, and encrypted credential storage</li>
<li><strong>Extensible</strong> -- hook into the generation pipeline with WordPress filters and actions</li>
</ul>
